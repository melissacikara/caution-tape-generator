Four Design Directions
All four directions share the same dark mode foundation, Bebas Neue + DM Mono type system, and caution yellow accent. What differs is the structural philosophy — how much presence the UI has around the tape.

The core question across all four directions: how much does the UI get out of the way? Direction A says almost completely. Direction C says the UI itself should feel like a warning system. B and D fall in between — B more structured, D more dramatic. All four commit fully to the industrial aesthetic.

Direction A
Pure Warning
Character
Minimal, almost recklessly simple. The tape is everything. The UI barely exists.
Direction B
Command Center
Character
Structured and official. Like a safety management dashboard. More chrome, more system.
Direction C
Brutalist
Character

Direction D
Cinematic
Character
The tape is a gallery piece. Dramatic negative space, glowing presence, input floats below.
What to Look For
First Impression
Which direction makes you immediately understand what to do — without reading anything?
In-Group Moment
Which would you feel confident pulling out in front of friends? Which feels like it would draw people in?
Brand Fit
Which takes the bit most seriously? Which looks most like it could be a real industrial warning system?
Mobile Feel
Which layout feels most comfortable to use one-handed, in a dimly lit room, while other people watch?
Direction A
Pure Warning
Maximum restraint. CAUTION: dominates the homepage in giant type. The input is borderless — just a cursor. The tape preview occupies the negative space below. Generate and a library link are the only affordances. Nothing competes for attention.
